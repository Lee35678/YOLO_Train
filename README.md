# YOLO_Train

YOLO26 파인튜닝 학습 인자(전이 학습·배치·AMP·프리징·학습률 등)를 슬라이더로 조작하며 익히는 단일 HTML 인터랙티브 교재.

## 개요

`yolo26_full_lesson.html` 한 파일로 된 교재다. 왼쪽 목차에서 장을 고르면 설명과 함께
위젯(슬라이더·버튼·차트)이 나오고, 값을 바꾸면 결과가 바로 갱신된다.
`model.train(...)`에 넘기는 인자들이 학습 속도와 결과에 어떤 영향을 주는지 감을 잡는 것이 목적이다.

## 주요 내용

| 장 | 다루는 내용 | 위젯 |
|---|---|---|
| 전이 학습과 파인튜닝 | 클래스 수가 달라도 백본 가중치가 넘어오는 이유, 수렴 속도, 이름만 다른 클래스 살리기, 작은 모델부터 시작하기 | 가중치 전이 지도, 전이 학습 vs 처음부터 학습, 클래스 별칭 동기화, 모델 용량 대 데이터 양 |
| 하드웨어 리소스 최적화 | 배치 크기와 VRAM, 캐싱(`cache`), AMP(`amp`), 분산 학습 | 배치 크기·VRAM·처리량, I/O 병목 타임라인, AMP 켬/끔 |
| 데이터 학습 및 일반화 전략 | `fraction`으로 부분 집합 리허설, `scale`과 `multi_scale`의 차이 | 부분 집합 학습, 증강 미리보기 |
| 하이퍼파라미터와 옵티마이저 | 에폭과 조기 종료(`patience`), `optimizer=auto`의 동작, 자주 걸리는 함정, 학습률 스케줄(`lr0`, `lrf`, warmup) | patience 조기 종료, 옵티마이저 자동 선택, 학습률 곡선 |
| 프리징과 2단계 파인튜닝 | `freeze` 값이 얼리는 범위, 상황별 선택, 2단계 파인튜닝 | 레이어 프리징 다이얼, 상황 → 권장 프리징, 단일 단계 vs 2단계 |
| 흔히 겪는 문제와 해결 | 아무것도 예측하지 못함, mAP 조기 정체, 새 클래스 학습 시 기존 클래스 망각 | 진단 순서, conf 임계값, 정체 원인과 처방, 클래스 불균형과 `cls_pw`, 망각 완화 전략 비교 |
| 종합 콘솔 | 앞에서 배운 인자를 한 화면에서 함께 조절. 시나리오를 고르면 일부러 잘못된 설정에서 출발해 권장 설정까지 고쳐 나간다 | 설정 / 진단 패널, 배포용 체크리스트 |

## 기술 스택

HTML, CSS, Vanilla JavaScript (외부 라이브러리 없음, 폰트만 Google Fonts에서 불러옴)

## 실행 방법

설치할 것이 없다. 파일을 브라우저로 열면 된다.

```bash
# 저장소를 받은 뒤
start yolo26_full_lesson.html      # Windows
open yolo26_full_lesson.html       # macOS
xdg-open yolo26_full_lesson.html   # Linux
```

## 폴더 구조

```
YOLO_Train/
└── yolo26_full_lesson.html   # 교재 전체 (스타일·스크립트 인라인)
```

## 참고

- 교재 속 그래프와 수치는 브라우저 안에서 계산한 설명용 근사치다. 실제 YOLO 학습을 돌린 결과가 아니고, 학습 코드나 데이터셋도 들어 있지 않다.
- 인터넷이 끊겨 있으면 Google Fonts를 불러오지 못해 시스템 기본 글꼴로 표시된다.
